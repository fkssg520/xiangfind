# 小冯的协作节奏（自用备忘）

> 本文件由 agent-b 维护。目的是让**换会话、换机器之后的我**不用重新摸索该多久看一次消息。
> 不属于协议正文，与 `AGENTS.md` / `docs/分工协议.md` 冲突时以后者为准。

---

## 1. 看消息的三个固定时点

| 时点 | 做什么 |
|---|---|
| **每轮开口第一件事** | `scripts/sync.ps1` + `gh api notifications`（看未读）+ 查我开着的 PR 的 `reviewDecision` |
| **每次 push 之后** | 等 30 秒再看一次 PR，确认没被立刻打回 |
| **收工前** | 把 `to:agent-b` 的 issue 全过一遍，能回的回掉 |

**为什么单列 PR 的 `reviewDecision`**：`sync.ps1` 只列 issue，**小灰的正式评审意见写在 PR review 里，sync 看不到**。2026-11-19 就因为这一点漏掉了他 02:31 的 CHANGES_REQUESTED，直到人类提醒才发现。

## 2. 1 分钟催办规则（人类 2026-11-19 指令，后收紧为 1 分钟）

发出**需要对方动作**的消息（请求 review、提问、交接）之后：

```
1 分钟无回应 → 催一次（只催一次）
之后 → 按 L1 沉默规则等 24 小时，再按"我倾向于"自行推进
```

**催的写法**（不要只是"在吗"）：

```
提醒一下：<PR #x / issue #x> 还在等 <具体动作>。
我这边已 <已完成的状态>，没有阻塞我的其它活，先去做 <下一步>，有反馈随时打断我。
— 小冯
```

**为什么是 1 分钟**：人类 2026-11-19 明确要求「一分钟没回就催下」。对方 AI 不会自己醒，早催一次比干等有效。

**为什么只催一次**：两个 AI 互相催会变成噪音，第二次开始就等 L1。

## 3. 交接纪律（D-010）

需要对方做的事 → **停下来等确认**，不自己绕过去、不替对方做。
停等期间只做**不受影响的部分**（L2 停摆规则）。

## 4. 环境自检

每台新机器/重装后先跑：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File D:\Deepseek\tools\bootstrap.ps1
```

它会恢复 Node / gh / git 配置 / GitHub 代理 / 仓库状态。**GitHub 走本机 CONNECT 代理（127.0.0.1:7899）**，不再依赖 hosts 固定 IP。

## 5. 开分支前必须同步 main（2026-11-19 教训，栽了两次）

```powershell
git checkout main
git pull --ff-only
git checkout -b b/xxx
```

**为什么**：#41 和 #42 两轮都因为**分支起点是旧的**导致 PR 冲突，小灰那侧等了 10 分钟才处理，
第二次他直接替我解了 CSS 冲突（随后被人类按 D-013 纠正）。冲突的根因在我，不在他。

**判断依据**：`git log --oneline origin/main..HEAD` 里出现**别人的 commit**，说明分支起点过期了。

## 6. 合并 UI 类 PR 前先跑 E2E

```powershell
npm run dev                                                # 另开窗口
powershell -NoProfile -ExecutionPolicy Bypass -File tests/e2e/run.ps1
```

**为什么**：2026-11-19 晚上，main 上 `app.js` 出现 `openClaimDialog` 重复声明，
整个模块解析失败——**页面骨架正常，但所有交互全死**（登录没反应、广场空白）。
这种 bug 看 diff 发现不了，只有跑起来才暴露。E2E 就是那时候补的，6 个场景。

**合并方（小灰）也应该跑**，我在每个 UI PR 里都写了这句话。

## 7. 对方没回时（D-013，适用于双方）

需要对方动作而对方没回应时，我能做的只有两件：

1. 在对应 PR / issue 里**提醒一次**
2. **告诉人类「他没回，等你决定」**

然后停手。**不替他改代码、不替他合并、不绕过评审**。

等待期做这些（不碰他的文件、不开新功能分支）：
- 静态自检（重复声明、重复 id、CSS 花括号、冲突标记残留）
- 更新自己的文档与节奏记录
- 把待办整理成清单，等他回了一条条推
