# 设计规范（赤陶暖调）

> **本文件是界面唯一依据**，覆盖 `docs/需求基线.md` §5 的旧配色与圆角规定（见 `决策记录.md` D-006）。
> 小冯按本文件实现，小灰按本文件验收。取自项目负责人提供的 `design.md`。

---

## 1. 一句话气质

赤陶、沙、奶油：地中海的午后。暖调、手作感、留白宽松。
**全站禁用蓝、紫等冷色**；阴影是暖色（赤陶 10%），不是灰黑。

## 2. 颜色

| 名称 | 值 | Token | 用途 |
|---|---|---|---|
| Terracotta | `#b5654a` | `--color-terracotta` | 主色：主按钮、主强调 |
| Cream | `#faf5ef` | `--color-cream` | 页面底 |
| Sand | `#d4a373` | `--color-sand` | 第一层次色，区块底 |
| Earth Brown | `#7a6350` | `--color-earth-brown` | 正文与第二层次 |
| Olive | `#8b9d77` | `--color-olive` | 标签、自然语义 |
| Fresh Green | `#8fb86a` | `--color-fresh-green` | 仅"新芽/春季"，**业务界面不要用** |

### 状态色映射（覆盖需求基线的"琥珀/红"）

需求基线要求"琥珀色进行中、红色失物"，但本设计禁止冷色与纯红，故映射为：

| 业务状态 | 颜色 | 说明 |
|---|---|---|
| 失物（lost） | `--color-terracotta` `#b5654a` | 取代旧"红色失物提示" |
| 进行中（open / pending / pending_storage） | `--color-sand` `#d4a373` | 取代旧"琥珀色" |
| 已存放 / 待领取（stored / ready_for_pickup） | `--color-olive` `#8b9d77` | 正向进展 |
| 已完成（returned / reunited） | `--color-olive` 加深 10% | 结束态 |
| 已归档（archived） | `--color-earth-brown` 60% 不透明 | 弱化 |

> 不允许用纯红 `#f00`、纯绿、蓝紫色。状态必须有**文字**，不能只靠颜色（无障碍要求）。

## 3. 字体

**衬线**（手作感，字距微开 0.01em）：

```css
--font-serif: 'Lora', Georgia, 'Songti SC', 'Noto Serif SC', 'SimSun', serif;
```

> Windows 无 `Songti SC`（macOS 字体），回退到 `Noto Serif SC` / `SimSun`；中文用宋体系。

| 角色 | 字号 | 行高 | 字重 | Token |
|---|---|---|---|---|
| display | 48px | 1.2 | 600 | `--text-display` |
| heading | 36px | 1.3 | 600 | `--text-heading` |
| subheading | 28px | 1.4 | 400 | `--text-subheading` |
| body-lg | 21px | 1.7 | 400 | `--text-body-lg` |
| body | 17px | 1.75 | 400 | `--text-body` |
| label | 14px | 1.55 | 600，字距 0.1em | `--text-label` |

## 4. 间距、圆角、布局

- 基准单位 **8px**；间距阶：8 / 16 / 24 / 32 / 48 / 64 / 96 / 128
- 圆角：**卡片 12px**、按钮 8px、输入 8px、陶罐装饰 `999px 999px 40% 40%`
  - ⚠️ 需求基线原要求"卡片圆角 ≤ 8px"，**本设计覆盖为 12px**（D-006）
- 页面最大宽 **1080px**，容器内边距 24px
- 区块间距 112px，卡片内边距 32px，元素间距 24px
- 允许轻微不对称（5:7 双栏）

## 5. 阴影（暖色，禁止灰黑）

```css
--shadow-warm:    0 6px 20px rgba(181,101,74,0.10);
--shadow-hover:   0 12px 32px rgba(181,101,74,0.16);
--shadow-pressed: 0 2px 6px rgba(181,101,74,0.12);
```

## 6. 组件

| 组件 | 规格 |
|---|---|
| **主按钮** | 赤陶填充、奶油字、8px 圆角、无描边、17px/600、padding 14px 32px；hover 填充加深 `#a1563f`、阴影扩到 32px；**按下 `translateY(2px)` 压印，不做缩放**；过渡 200ms ease-out |
| **卡片** | 奶油或沙 18% 填充、12px 圆角、1px `rgba(122,99,80,0.12)` 描边、padding 32px、暖阴影；hover 上浮 2px + 阴影扩大 |
| **输入框** | 奶油填充、8px 圆角、1px `rgba(122,99,80,0.25)` 描边、padding 12px 16px、17px 衬线；占位符 45%；聚焦描边转赤陶 + 2px 赤陶 20% 外环 |
| **区块底** | `rgba(212,163,115,0.18)` |
| **陶罐装饰** | 可用 CSS border-radius 画轮廓，填沙/赤陶 20%-35%，64-160px，单屏 2-3 处，不干扰内容 |

## 7. 必须遵守 / 禁止

**Do**
- 奶油底 + 赤陶 + 大地色
- 暖色阴影
- 点击下沉压印（不是缩放）
- 橄榄绿作自然元素
- 留白宽松，用阴影把元素抬起来而不是靠边框

**Don't**
- 不要蓝、紫等冷色
- 不要灰黑阴影
- 不要弹性缩放反馈
- 不要金属高光
- 渐变透明度不超过 60%（是气息不是色块）
- 不要巨大的营销标题、装饰性渐变球、卡片套卡片、只有说明没有操作的页面

## 8. 响应式（保留需求基线的硬指标）

- **390px**：单列，无横向溢出（验收项 A-07）
- **1280px**：多列，信息密度适中
- 项目要求的最小可用宽度：375px
